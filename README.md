# Pets SuperApp (рабочее название: Lucky Paul)

Экосистема для владельцев питомцев: маркетплейс товаров (свой бренд + партнёрские бренды), профиль питомца, бронирование услуг, комьюнити.

## Текущий статус

В `prototype/lucky-paul.html` — интерактивный кликабельный прототип (single-file HTML/CSS/JS), который задаёт целевой UX и структуру данных перед началом реальной разработки. Открывается просто в браузере, без сборки.

### Разделы прототипа

- **Home** — главный экран
- **Marketplace** — собственный бренд *Lucky Paul* (ошейники, поводки, GPS — производство TIZE, Шэньчжэнь) + товары партнёрских брендов (PetSafe, Ruffwear, Royal Canin, Purina, Acana, Orijen, Hill's, Whistle, Fi, Tractive, PitPat и др.) по категориям: ошейники, поводки, GPS-устройства, корм
- **Pet Profile** — карточка питомца: вес, активность, вакцинация с обратным отсчётом, документы (паспорт, сертификаты, родословная), история заказов и бронирований
- **Services** — бронирование услуг: ветеринария, груминг, тренировки, передержка, выгул (сервис ориентирован на рынок ОАЭ/Дубай)
- **Community** — лента постов владельцев питомцев с тегами и комментариями
- **Cart / Checkout** — корзина и модалки оформления

## Структура

- `frontend/` — мобильный клиент (в разработке)
- `backend/` — серверная часть / API (в разработке)
- `database/` — схемы, миграции (в разработке)
- `prototype/` — кликабельный HTML-прототип текущего UX (справочник для дизайна и разработки)

## Workflow

- `main` — рабочая (стабильная) ветка, прямых пушей избегаем
- Новая задача → отдельная ветка `feature/...` или `fix/...`
- Изменения проходят через Pull Request перед merge в `main`
