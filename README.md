# Pets SuperApp

Mobile app project — frontend + backend + database.

## Структура

- `frontend/` — мобильный клиент
- `backend/` — серверная часть / API
- `database/` — схемы, миграции

## Workflow

- `main` — рабочая (стабильная) ветка, прямых пушей избегаем
- Новая задача → отдельная ветка `feature/...` или `fix/...`
- Изменения проходят через Pull Request перед merge в `main`

## AI-инструменты

Репозиторий подготовлен для работы с AI coding-агентами (Claude Code, Codex и т.д.) — они видят полную структуру и историю проекта через GitHub.
