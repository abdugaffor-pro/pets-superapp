# Прототип Lucky Paul

Статический интерактивный прототип (один файл, HTML + CSS + JS, без сборки и зависимостей).
Мобильная версия — с нижней навигацией и адаптивной сеткой (открывается по ссылке в браузере телефона).

## Как открыть

Просто открой `lucky-paul.html` в любом браузере — двойным кликом или через "Open File".
Для работы карты (см. ниже) нужен обычный доступ в интернет у того, кто открывает файл —
он подгружает библиотеку карт и тайлы карты с публичных серверов.

## Что уже работает

- Маркетплейс: каталог, поиск, сортировка, корзина, оформление (демо).
- Профиль питомца: здоровье, вакцинация, документы, история заказов, записи.
- **Карта на OpenStreetMap (бесплатно, без API-ключа)**:
  - Раздел «Услуги» → переключатель «Список / На карте» — все специалисты на карте
    Дубая, клик по метке открывает карточку с ценой и кнопкой «Забронировать».
  - Профиль питомца → блок «Последнее местоположение» — демо-точка на карте
    (заглушка под будущий GPS-трекер питомца).
- Услуги: бронирование реально добавляет запись в профиль питомца («Предстоящие записи»).
- «+ Добавить питомца» — реальная форма, питомец добавляется в переключатель питомцев.
- Документы питомца → «Просмотреть» — открывает превью карточки документа (демо, без реального файла).
- Сообщество: лайки кликабельны (счётчик реально меняется), можно оставить комментарий к посту.

## Зачем нужен

Это референс UX/UI и структуры данных (товары, профили питомцев, услуги, посты комьюнити) для будущей реальной разработки frontend/backend. При переносе в продакшн-стек данные из `PRODUCTS`, `PETS`, `SERVICES`, `COMMUNITY_POSTS` (внутри `<script>`) — хорошая отправная точка для схемы БД и API.
